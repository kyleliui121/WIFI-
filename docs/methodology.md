# 仿真方法、参数与可复现性说明（A 班）

> **重要：** 本项目实现课程指定的 **简化模型**，不宣称复现完整 IEEE 802.11bn 草案，也不宣称硬件性能预测。提交论文前应将本页和生成数据逐项审查。

## 1. 场景及公平比较

- 智能停车场/充电站，一个 AP，`N∈{10,20,30}` 辆车；其中 **2** 辆高优先级业务（100 B，严格每 10 ms 入队，截止时延 10 ms），余下 `N-2` 辆低优先级业务（1500 B，饱和发送）。每站只承载一种业务，所有站互相可听，忽略传播时延、隐藏终端和误码。
- 四种方案：`DCF`（高、低业务均使用 CW 15/1023、DIFS）；`EDCA`（高 AC_VO、低 AC_BE）；`P-EDCA`（EDCA + 紧急队列规则）；`NPCA`（**EDCA + P-EDCA + NPCA**，不是单独 NPCA）。
- 主信道的外部网络占用日历对所有四种方案**相同**（相同 `seed` 生成），避免将外部占用的随机差异误当作算法改进。算法自身的随机退避使用每站单独固定的随机种子。不同模式的抽样顺序随竞争过程改变，因而不是每次退避相同。
- 论文对比用 `N=10/20/30`、随机种子 `42/43/44`、每次 **10 秒**；DCF 校验使用 N=5,10,...,50、相同种子与仿真时长。修改 `--bianchi-step 1` 可逐一扫描 N=5..50。

## 2. MAC 时序、碰撞及重传

| 参数 | 数值 |
|---|---:|
| 时隙 | 9 μs |
| SIFS | 16 μs |
| PHY 前导 | 20 μs |
| 速率 | 54 Mbit/s |
| ACK 长度 | 14 B |
| 重传上限 | 7 次重传（共 8 次尝试） |
| DCF | AIFSN=2，CWmin=15，CWmax=1023 |
| AC_VO | AIFSN=2，CWmin=3，CWmax=7 |
| AC_BE | AIFSN=3，CWmin=15，CWmax=1023 |

任意站点帧的 AIFS = `SIFS + AIFSN * slot`。退避从 `U{0,...,CW}` 抽取，冲突后 `CW_r = min((CWmin+1)*2^r - 1, CWmax)`。各站维护独立的剩余 AIFS、剩余整数退避时隙，**仅在所在信道空闲时递减**；一旦介质忙，冻结退避并在忙期结束后重新等待 AIFS。已完成的完整退避时隙不会丢失，未完成的不足一个时隙的进度在忙期结束时清零。

相同信道上恰好同时进入发送状态的站点都记一次失败的**发送尝试**，单次两站冲突对应两次失败尝试。成功占用时长约为 `PHY_DATA + SIFS + PHY_ACK`；冲突时长采用 `最长 PHY_DATA + SIFS + PHY_ACK` 作为 ACK 超时近似。忽略 RTS/CTS、随机物理误码、EIFS、聚合帧、TXOP 和站内虚拟碰撞。

**不可将其视为严格标准 802.11 时序**：抽象化的 ACK timeout 与 AIFS 相位对毫秒以下时延、理论 Bianchi 差值可能有影响。

## 3. P-EDCA：明确的自定义简化规则

高优先级队首帧满足**任一**条件即标记为紧急：

1. 自进入队列起等待 ≥ **5 ms**（截止时间 10 ms 的一半）；
2. 该帧失败次数 ≥ **2**。

变紧急后 AIFSN=**1**，CWmin=**1**，CWmax=**3**。在途退避剩余量截断至至多 3 个时隙；如已完成部分 AIFS，则将剩余 AIFS 截断为新 AIFS 时长。结束当前帧后新帧恢复 AC_VO 基本参数。低优先级参数不改。

此策略是小组自定义的 **P-EDCA 教学模型**，**不是** IEEE 802.11bn 的规范参数/标准兼容实现。

## 4. NPCA：外部占用 + 双信道切换

- 主信道的邻网忙期按 `Exp(mean=2 ms)` 抽样，闲期按 `Exp(mean=2*(1-0.30)/0.30 ≈ 4.667 ms)` 抽样，因此 **长期目标外部忙占比 30%**；具体 10 秒运行的观测比率由随机序列决定，不强制刚好 30%。
- 无 NPCA：所有站点只使用主信道，外部忙期暂停信道竞争；主信道忙期结束后重新等待相应 AIFS。
- 有 NPCA：**仅高优先级**站点在外部忙期开始后切换至非主信道、结束后切回主信道；每次切换冻结退避并耗时 **100 μs**；退避余量保留但重新等待 AIFS。非主信道无外部邻网占用，仍可能发生两辆高优先级车之间的同信道碰撞。
- 低优先级车**始终停留在主信道**，以便衡量高优先级受益和低优先级吞吐量代价。高优先级在辅助信道发送时不会与主信道的低优先级车碰撞，两个信道可并行工作。
- 为避免建模“尚未完成的 802.11bn 外部网络互相碰撞”，采用**预生成的外部占用时间表和不可跨越邻网忙期的原子数据帧**：若数据帧+ACK 将跨过下一次邻网忙期起点，暂缓该主信道发送直到本次邻网忙期结束。**这一简化使用了未来占用日历，理想化程度较高，可能高估有效吞吐量与 NPCA 改善，应在论文中作为局限性说明**。
- 不模拟多链路协商、CCA 门限、宽带信道、真实 PHY MCS、实际非主信道可用性或信道切换的硬件实现，因此不能用于 Wi-Fi 8 商用设备性能预测。

## 5. 统计口径（务必保持一致）

| 指标 | 统计定义 |
|---|---|
| 高优先级均值、p99、p99.9 接入时延 | **仅成功收到 ACK 的高优先级帧**，从入队到 ACK 完成，按帧聚合后计算；每个种子单独计算分位数 |
| CCDF | N=30 时三个种子的成功高优先级帧延迟合并，`P(D≥d)`；纵轴对数；**不包括未成功帧** |
| 成功帧接入时延超时率 `high_success_late_pct` | 分子：成功收到 ACK 且 D > `deadline_us` 的高优先级帧数 `high_success_late`；分母：所有成功高优先级帧数 `high_success`；乘 100%。恰好在截止时刻完成不算超时 |
| 丢帧率 `high_drop_pct` | 分子：重传超限丢弃的高优先级帧数 `high_dropped`；分母：`high_resolved = high_success + high_dropped`；乘 100%。截止前丢弃也计丢帧，但**不计入成功帧超时数** |
| 综合截止失败率 `deadline_failure_pct` | 分子：`high_deadline_failure = high_success_late + high_dropped`；分母：`high_resolved`；乘 100%。表示已确定结果中未能按时成功交付的比例，包含截止前丢弃 |
| 未完成帧数及占比 `high_unfinished` / `high_unfinished_pct` | 仿真终止时仍在队列/处理中、结果右删失的高优先级帧数；占比的分子为 `high_unfinished`，分母为全部生成帧数 `high_generated`，乘 100%。即使已经超过截止，也不混入上述已确定结果指标 |
| 低优先级总吞吐 | 成功发送的低优先级**有效载荷** bit 数 / 10 秒，Mbit/s |
| 碰撞概率 | 碰撞的站点发送尝试数 / 所有站点发送尝试数；与“碰撞事件数 / 竞争轮次”不同 |
| 等效行驶距离 | p99.9(ms) × (10/3.6 m/s) × (0.001 s/ms) × 100 cm/m = **0.27778 × p99.9(ms)** cm |
| 重复实验误差条 | 每个 N、每个模式，三个随机种子的指标 **均值 ± 样本标准差**；对 p99.9 不是置信区间 |

所有比例在分母为零时输出 `None`（CSV 空单元格），表示无可统计样本，并非 0%。计数满足 `high_generated = high_success + high_dropped + high_unfinished`，成功超时是成功帧的子集。

输出字段迁移：旧 `deadline_miss_pct` 更名为 `deadline_failure_pct`，原有综合公式保持不变；旧内部计数 `high_deadline_miss` 移除，综合计数由 `high_success_late + high_dropped` 推导。旧数据中的 `deadline_miss_pct` 应解读为综合截止失败率，不能当作成功帧接入时延超时率；后者无法仅凭旧综合比例直接恢复，需使用成功帧时延明细或重新运行实验。

尤其在 DCF 下，高优先级帧可能明显积压。**只看成功帧的 p99.9 存在幸存者偏差**；必须结合未完成占比、成功帧超时率、丢帧率及综合截止失败率分析，不能据此宣称全部业务满足截止时延。

## 6. Bianchi 模型

对饱和 DCF 中单站的条件碰撞概率 `p` 和每个虚拟时隙的发送概率 `τ`，采用经典独立碰撞近似：

`p = 1-(1-τ)^(N-1)`。

理论求解等价于 Bianchi 封顶退避阶段 `m=6`、初始窗口大小 W=16 的经典式：

`τ = 2(1-2p) / [(1-2p)(W+1) + p*W*(1-(2p)^m)]`。

为避免 `p≈0.5` 附近数值抵消，程序用加权阶段驻留时间的等价求和形式数值求值，再通过 `scipy.optimize.brentq` 求固定点；另给有限重传 R=7 的阶段加权校正曲线。与仿真不完全重合的可能原因包括有限重传、非理想独立碰撞假设、碰撞后计时简化与有限观测样本。
