## 运行

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m wifi_sim.experiments --out results/matrix --duration 10 --seeds 42 43 44
python -m wifi_sim.acceptance results/matrix --write-report
python -m tools.demo_npca --duration 10 --seeds 42 43 44 --out results/npca
python -m tools.analyze_28 --results results/matrix --out results/analysis28
```

Windows 下也可在仓库根目录双击 `run_experiments.bat`、`run_npca_demo.bat`、`run_analysis.bat`，或在 VS Code 里选择对应的运行配置。第 28 条读取第 27 条生成的矩阵结果。

实验会在每组结束后更新 CSV。打包或分析前应等命令跑完，再用 `wifi_sim.acceptance` 验证输入目录。图 01–04 由实验矩阵生成，图 05–06 由第 28 条脚本生成。

## 阅读结果

- 高优先级时延分位数只统计成功帧。评价 DCF 等方案时应同时查看截止失败、丢弃和未完成帧。
- NPCA 的切换范围限于高优先级站点。模型使用独立辅助信道和预生成的外部占用日历。
- 复核入口和结果文件说明见[接手指南](接手指南-ONBOARDING.md)。
